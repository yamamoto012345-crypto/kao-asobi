# かお父さん（旧仮称：かおあそび）

自分（子ども・家族）の顔をカメラで撮って、指でつついて・引っ張って・ふくらませて遊ぶスマホ向けPWA。
「ふうせんわり」「アプリ（仮）」と同じ構成（index.html／style.css／app.js／manifest.json／sw.js／icons）。

## 遊び方
- ホーム →「しゃしんを とる」（自撮りカメラ。🔄で外カメラ）または「しゃしんを えらぶ」。
- 触り方で自動的に変わる（道具の切替ボタンなし）：
  - 指1本でなぞる＝つまむ／押しっぱなし＝ふくらむ（長いほど大きく）／円をかく＝ぐるぐる
  - 指2本で近づける＝ぎゅー／広げる＝ふくらむ／ひねる＝ぐるぐる
  - 離すとバネでぷるんと戻る
  - **素早くはじいて離すと顔ごと飛んでいく**。画面の端で跳ね返ってぐにゃっとつぶれ、止まると中央へ戻る。飛んでいる顔を触るとつかまえられる
- 撮影ガイドの楕円の外側は白くなる（⚙で OFF 可。次の写真から反映）。背景は白。
- アクション：🍄おおきく（顔全体を大きく／もう一度で戻す）、⭐きらきら（虹色にゆれる）、🙈ばあ（いないいないばあ）。
- 💾 で今の顔をPNG保存（対応端末は共有シート）。
- 3分遊ぶと「おやすみ」（15秒は起きられない）。⚙で OFF にできる。

## プライバシー
- 写真は端末内でのみ処理。サーバーへ送らない。「つづきから」用に直近1枚を localStorage に保存（⚙から削除可）。
- 外部ライブラリ・外部通信なし（WebGL＋Canvas のみ）。顔認識もしない（指で触るだけ）。

## 動作条件
- カメラは **HTTPS か localhost** でのみ使える（GitHub Pages なら可）。ファイルを直接開く（file://）ではカメラ不可。「しゃしんを えらぶ」は可。
- WebGL が使える端末（一般的なスマホはすべて可）。

## 調整するところ（app.js 先頭）
- `step()` 内：`A`（ふくらみ／ぎゅー）・`S`（ねじれ）・`sig`（影響範囲）の係数。`STILL_R`＝「押しっぱなし」と「なぞる」の境目。
- `SLEEP_MS` / `WAKE_WAIT`：おやすみまでの時間／起きられるまでの待ち。
- `N`：メッシュ細かさ（36）。`FS`：顔の表示倍率（0.7）。`FLICK_MIN/FLICK_MAX`：はじきの最低・最高速度。`getMask()`：白く抜く楕円（幅56%×高さ76%＝撮影ガイドと同じ）。
- 今後の候補：顔の輪郭の自動認識（髪まで切り抜く。MediaPipe等のモデル約10MBを同梱する必要あり）。
